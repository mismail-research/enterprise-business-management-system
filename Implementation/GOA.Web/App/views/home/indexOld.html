    Global Opportunities Analysis

  • Welcome to the DurandalAuth sample project !!

    This template provides a way to authenticate users using Durandal and FormsAuthentication with an ASP SimpleMembership Provider.

  • Breeze for data management

    Client-side data management uses the excellent Breeze JS framework.

  • ASP MVC and Web API

    ASP MVC and Web API are used on the server-side.

  • Unit of Work and Repositories

    You will find an implementation of this pattern on both the server (Entity Framework) and the client (Breeze).

  • SEO Optimization

    The template is ready to be SEO crawlable using a headless browser

  • ... and of course

    My favorite tool ... Bootstrap for styling this site.

Why this project?

Because I couldn't find any proper way of working with this technology stack and this kind of authentication ... so I tried to write it myself.
